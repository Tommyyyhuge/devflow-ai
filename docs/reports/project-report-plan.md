### 1. 开场：项目定位 + 健康度看板（3分钟）

**核心信息**：
- **项目名称**：DevFlow —— 低成本 AI 编程助手
- **一句话定位**：让开发者用自然语言描述需求，AI 自动完成规划、编码、验证全流程

- **推荐方案**：**6 月 18 日（周三）**开源（v0.2.0 完成后，约 4 周准备期）

- **推荐方案**：当前单人开发可支撑到 v0.2.0，后续如需前端/UI 优化再评估增员

- **原因**：个人开发者/小团队是天然种子用户，开源是低成本获客的最佳路径

### 4. 产品功能展示（4分钟）

**已交付功能**：
1. **自然语言编程** —— 描述需求，Agent 自动规划→编写→验证
2. **双界面支持** —— CLI（终端）+ Web UI（浏览器），支持深色主题

5. **对话历史管理** —— 持久化存储，支持多轮对话回溯
6. **预算保护机制** —— 内置 $20/周 + $3.5/5小时上限，超支自动拒绝

### 5. 技术架构概览（2分钟）【精简版】

**一句话总结**：采用 Python 成熟技术栈（FastAPI + Pydantic + Click），已在行业验证，聚焦业务逻辑而非技术冒险。

**简化架构图**（一页 PPT）：

```
用户界面层 (CLI / Web UI)
    ↓
Agent 引擎层 (规划 → 执行 → 验证)
    ↓
工具层 (文件/编辑/Shell/搜索/Git)
    ↓
LLM 层 (DeepSeek / OpenAI 兼容协议)
    ↓
代码理解层 (Tree-sitter + RepoMap)
```

**最新架构升级**：刚完成 **多 LLM Provider 支持**，采用工厂模式设计，未来可无缝接入 Ollama（本地模型），降低对单一供应商的依赖。

### 11. 收尾：问答（2分钟）

**预设高频问题**：

**Q1: 与 GitHub Copilot 的区别？**  
A: Copilot 是代码补全工具，DevFlow 是完整编程 Agent（规划→编码→验证）。DevFlow 开源、成本更低、有预算保护。

**Q2: 模型稳定性如何保证？**  
A: 刚完成多 Provider 架构，DeepSeek 不可用时可切换到 OpenAI 或其他兼容服务。

**Q3: 安全吗？AI 会执行危险命令吗？**  
A: 有安全审查机制，但 sandbox 模块还在开发中（预计 5/21 完成），建议生产环境配合容器化使用。

**Q4: 商业化前景？**  
A: 核心差异化是"低成本"，可吸引个人开发者和小团队。未来可考虑企业版（多用户、团队协作）。

**Q5: 需要多少预算？**  
A: 开发和测试阶段每月 $10-20（API 费用）。CI/CD 使用 GitHub 免费额度。
